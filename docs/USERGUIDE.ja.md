## はじめての起動

1. APKをインストールします（Androidに「不明なソース」の許可を求められたら許可してください）。
2. **設定 → Novel Updates にログイン** — 案内に従うとライブラリの規模を確認し、リストのダウンロードを提案します。
3. 任意：**設定 → 翻訳** — OpenAI互換のAPIキーを貼り付けるとAI機能（翻訳・カバー生成）が使えます。
4. 以上です。アプリは1日1回アップデートを確認し、変更履歴つきで提案します。

日本語サイトはアカウント不要です。すべての機能がすぐ使えます。

## Novel Updates で小説をフォロー

- **リーディングリスト**はドロワー（☰）に表示されます。リストをタップすると作品一覧、タイルの数字は未読話数です。
- 作品をタップ → 作品ページ：あらすじ・情報と、全話の**RELEASES**一覧。**READ CHAPTER**で続きから読めます。**MARK AS READ**はサイト側の既読に反映されます。
- 話のチェックボックスは、NUのリーディングリストマーカー（1作品に1つ）を移動します。
- 新着の**通知**はあなた専用のNUフィード経由で届きます。設定は不要です。ドロワーの「Lists ⚙」でリスト単位、作品ページのベルで作品単位でミュートできます。
- ある端末で読んだ位置は、NUの読書アクティビティ経由で他の端末にも自動同期されます。

## 日本語サイト

ドロワーを開き、サイトチップ（📖 Syosetu / カクヨム / AlphaPolis）をタップ。どのサイトもNUと同じレイアウトの作業スペースです：グリッド、バッジ、作品ページ、次話カード。

- **Discover（★）** — ランキングと詳細検索。R18姉妹サイトは設定の18+ゲートの内側にあります。
- **ログイン**（ドロワー）でサイトのブックマーク・フォローを同期。タイルを長押しするとサイト自身のカテゴリ間で移動できます。
- フォロー作品の更新通知は、NUと同じバックグラウンド確認で動きます。

## 章を読む

- ‹ 前へ / 次へ › で移動。⋮メニューに表示設定があります：**テキスト表示かWeb表示**、ページテーマ（セピア/ダーク/ライト）、明朝/ゴシック、文字サイズ。
- **テキスト表示**は抽出された本文をクリーンに表示します。抽出を防ぐサイトではフルページ表示に自動フォールバックします。
- 日本語の方向け：**単語を長押し**するとオフライン辞書（読み・品詞・意味）が出ます。
- 読了位置は作品ごとに自動保存。作品ページの「次の章」は常に続きを把握しています — v3c1がc20の後に来る巻番号リセットでも迷いません。

## オフライン読書と再ダウンロード

読んだ章はその場で自動保存されます。有効化は不要、それが既定です。

- **オフライン優先**：読んだことのある章を開くと、保存済みコピーが**ネットワークなしで一瞬**で表示されます。未読の章を取得するときだけサイトに問い合わせます。
- **⋮ → オフライン章** — この動作のスイッチ。オン（既定）=保存コピー優先、オフ=常にオンライン取得。
- **⋮ → 章を再ダウンロード** — 翻訳者が章を更新したときの切り札：サイトから再取得して保存コピーを上書きします。その章の翻訳は失われません。
- 旅行前に丸ごとオフラインにしたい？ 作品ページ → ⋮ → ダウンロード系メニュー（未取得のみ/全話再取得）。保存済みの章には✓が付きます。

## 自分のePubライブラリ

ローカルライブラリも同じドロワーの中に、独立した「サイト」として存在します：好きな数だけ作成できます（フィクション、ライトノベル…）— ☰ → サイトチップ → **＋ New library**。

**本の追加は3通り**（ドロワー）:
- **EPUBをインポート（コピー）** — ファイルをライブラリ専用の保存領域にコピーします。
- **端末内EPUBをリンク（コピーなし）** — 端末上のある場所から動かさず、その場で読みます。元のファイルは決して変更・削除されません。
- **フォルダごとリンク** — フォルダを一度選ぶだけで、中のePub全部（サブフォルダ含む）が単一の権限でライブラリに加わります。いつでも再実行OK — 新しいファイルだけ追加され、既存はスキップされます。

**構成の考え方**:
- 複数巻のePubはタイトルから自動で**シリーズ**にまとまります。シリーズページはサイトと同じINFO/RELEASESレイアウト、章一覧は**本自身の目次**に従います。
- **棚**はあなたのカテゴリ：Shelves ⚙ で作成、作品ページ（⚑）で割り当て、ドロワーで絞り込み、指紋で隠せる棚（18+方式）も。
- 検索ボックスの ✕ でクリア、下のチップは最近の検索（タップで再使用、長押しで削除）。

**自動グループ化が間違っていたら**（巻が単独シリーズになった、タイトルにコンマが紛れた）:
- はみ出したシリーズを開いて ⋮ → **別のシリーズに統合…** → 正しい方を選ぶ。全巻が移動します。
- またはグリッドでタイルを長押しして**複数選択** → 棚… / 統合… / 削除。

**健全性の維持**：同じファイルの二重リンクや、名前が微妙に違う再取得コピーなどの**重複**、移動・削除されたファイルの**死にリンク**（ドロワーに「🧹 行方不明 N 件 — 整理…」行が出ます）をバックグラウンドが監視します。削除は常に明示的なワンタップです。

## 翻訳

自分のキーを用意してください（設定 → 翻訳）。以下はすべてそのキーを使います。

- **読书中に** — ⋮ → 翻訳：章全体が翻訳され、段落の下に表示されます。スタイルルールにより、日本語小説の「」・心の声・オノマトペは保持されます。翻訳の表示/非表示とレイアウト（JPのみ / ENのみ / 両方）は翻訳サブメニューで切替。
- **作品ページ** — ⋮ → **タイトル・説明を翻訳**：原文の下に薄い英語行が表示されます。⋮トグルで表示切替。
- **ローカルライブラリのシリーズ全体** — 作品ページ → ⋮ → **全話を翻訳…**：全巻の全話を、進捗表示つき（「37/439」）で翻訳。翻訳済みの話はスキップされるので、いつ中断しても再実行で続きから。実行中はページを開いたままにしてください。

翻訳はアプリ内のサイドカーとして保存されます — ePubファイル自体は決して書き換えられず、本を削除すれば一緒に消えます。

## 読み上げ（TTS）

リーダーで ▶ をタップすると読み上げが始まります。3つのエンジン（設定）：**システムTTS**（ダウンロード不要、日本語対応）、**Kokoro**（オフライン・ニューラル英語）、またはキー経由のクラウド音声。コントロールバーは再生/一時停止、段落スキップ、段落タップでジャンプ、速度スライダー、スリープタイマー。ヘッドセットボタンにも対応します。

## 整理

- **グリッド**：長押し=複数選択 → 棚… / 統合… / 削除。選択タイルには✓。
- **ドロワー**：件数つきの棚（タップ=絞り込み、もう一度=解除）、ファイル喪失時の🧹行、ライブラリ管理（名称変更・保存場所）。
- **作品ページ**：⚑ 棚、⋮ に名称変更 / 説明 / カバー / 統合 / 翻訳 / 削除。左上のパンくずラベルで今いるライブラリ・シリーズを常に確認できます。
- **隠し棚**：Shelves ⚙ のスイッチをオンにすると、指紋解锁（ドロワーの「非表示を表示（18禁）」）まで全画面から消えます。

## カバー

カバーは各ePubから（サイト作品はサイトページから）自動で抽出されます。本当に画像がない場合は「No cover」プレースホルダーが出ます。直し方：巻ページ → ⋮ → **EPUBからカバー抽出**。シリーズページ → ⋮ → **カバーを選択…** で任意の巻のカバーに固定できます。カバーのないサイト作品にはAIアート（カバー生成）も使えます。

## バックアップと機種変更

設定 → ライブラリをバックアップ → ファイルを選択。バックアップにはリスト、カテゴリ/棚、設定、**ローカルライブラリの索引**（シリーズ・棚・グループ化）が含まれます — ePubファイル自体とログイン情報は含まれません。新しい端末で復元してからフォルダを再リンクすれば、すべて元どおりに。各サイトへのログインはやり直してください。

## トラブルシューティング

- **章がローディング画面のまま** — （初回のみ）サイトから取得しています。本当に止まったら接続を確認し、章を開き直してください。保存済みの章は常に一瞬で開きます。
- **NUで「Site parse returns nothing」** — サイトがチャレンジページを返しました。プル・トゥ・リフレッシュを一度。Cloudflare確認が出たら完了すると自動リトライします。
- **インポート後にカバーがない** — バックグラウンドで最初の1分ほどで埋まります。⋮ → EPUBからカバー抽出で即時強制。
- **余計な巻がある** — 同じファイルの二重リンクの可能性。クリーンアップが検出するか、余分な方を手動削除。
- **翻訳に失敗** — 設定のキーを確認。ステータス行に原因が表示されます。

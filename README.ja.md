# NovelNotifier

[English](README.md) · [日本語](README.ja.md)

ウェブ小説のためのAndroidアプリ。[Novel Updates](https://www.novelupdates.com)のリーディングリストをフォローし（表紙・未読数・新刊通知・既読管理）、日本のウェブ小説サイト [小説家になろう](https://syosetu.com) と [カクヨム](https://kakuyomu.jp) ではランキング・検索・アプリ内閲覧・オフラインePub作成まで、3サイトすべてを一つのアプリで。

本アプリは、放置された「Notifications for Novel Updates」（2019年リリース止まり、現在使用不可）のクリーンルームによる完全新規実装です。Novel Updatesには公開APIがないため、ログイン済みブラウザと同じ方式 —— 独自セッションを持つ組み込みWebView —— でサイトを読み取り、既読化・リスト変更などの書き込みもウェブサイトと同じエンドポイントで行います。一方、日本のサイトは公式・公開API（なろうはドキュメント公開済みのJSON API、カクヨムは公式サイト自身が使うオープンなGraphQLエンドポイント）経由なので、スクレイピングは発生しません。

## インストール

[Releases](https://github.com/PatchScratch/NovelNotifier/releases) から最新の `NovelNotifier-v<バージョン>.apk` をダウンロードしてインストールしてください（必要に応じてブラウザに「不明なソース」のインストールを許可）。アップデートは上書きインストールで、ライブラリはそのまま残ります。

**アプリ内セルフアップデート**: インストール後は1日1回GitHubを確認し、変更履歴付きでアップデートを提案、その場でダウンロード＆上書きインストールします（インストールごとにAndroidが確認を求めます）。アップデート後の初回起動時には変更履歴ポップアップが表示されます。

**Obtainium経由**：このGitHubのURLをアプリに登録すれば、アップデートが自動で届きます。どちらの方法でもOK — 併用しても競合しません。

**最初の一歩**：設定 → 「Novel Updates にログイン」（以降はオンボーディングが案内）。AI機能を使いたい場合は 設定 → 「翻訳」にOpenAI互換のAPIキーを貼り付け（任意）。日本のサイトはアカウントなしで利用できます。

## 主な機能

### NUライブラリの同期
- **リーディングリスト** — NUの全リストをドロワーで表示。グリッド/リスト切替、検索、4種の並べ替え、最終閲覧位置からの未読バッジ。
- **初回オンボーディング** — ログイン後にリストを読み取り、ライブラリの規模と全体ダウンロードの所要時間（控えめな推定）を表示。優先リストを1〜3個指定すると、その章データが先に届きます。進行カウンターもライブ表示。
- **バックグラウンド・ライブラリ同期** — まず表紙（視覚的に、オフラインで）、次に章リストを、礼儀正しいペースで1リクエストずつ（進捗通知付き：`Lists 3/15 · Covers 120/1419 · …`）。キューは再起動やバッテリー切れを生き延び、止まった場所から再開。
- **章通知** — 個人用NU RSSフィード（リーディングリストページから自動取得 — URLコピペ不要）、またはフィードなしの場合は間隔を空けたリスト巡回で新刊を検出。リスト別・作品別のミュートスイッチ。
- **端末間の既読同期** — ある端末で既読にした章は、NUの既読アクティビティフィード経由で他の端末でも既読になります。
- **シリーズページ** — INFO + RELEASES全行（ページ単位でキャッシュ）、次章カード、既読化・リスト変更はサイトへ書き戻し。
- **アプリ内リーダー** — 章行・READ CHAPTER はアプリ内で開き、‹ 前 / 次 › で書籍を移動。
- **オフラインライブラリ（ePub）** — リーダーの⋮メニューから作品ごとにオプトイン。読み進めながら標準ePubブックに保存（表紙・完全な目次付き）、または章リスト全体を一括ダウンロード。オフラインでも保存済み章は表示され、ブックは他の電子書籍アプリへエクスポート・共有可能。ユーザーの許可なく保存されることは一切ありません。**リーダービュー**（章本文を抽出してネイティブ描画 — セピア/ダーク/ライト、セリフ/サンセリフ、文字サイズ調整）と **Webビュー**（ページ全体）の2方式。抽出は計算済みスタイルで隠しデコイを除外し、敵対的なホストではページ単位でWebビューにフォールバック。作品別のJavaScript切替、広告・トラッカーホスト遮断、ポップアップ無効、ブラウザで開く逃げ道。
### なろう・カクヨム（日本サイト）
サイトごとに独立したワークスペース（ハンバーガー → サイトチップ）。公式・公開API経由で、スクレイピングなし。**どのサイトも同じデザイン言語** に従います — 作品ページ・未読バッジ・並べ替え・通知は、すべてNUモデル。

- **どのサイトでも同じ作品ページ** — INFO / RELEASESタブ、READ CHAPTER・MARK AS READ付きの次章カード、訳文付きのあらすじ・ジャンル・タグ、作品別通知トグル、CHANGE LIST位置にグループ/分類ピッカー。1つの共有テンプレートがすべてを描画し、サイトはデータと書き戻しルール（NUのリストマーカー、なろうのしおり、カクヨムの閲覧履歴）だけを提供します。
- **未読バッジもどこでも** — 閲覧位置はサイトごとに追跡され（NUの最終閲覧、なろうのしおり、カクヨムの閲覧履歴）、タイルのバッジ・「読了 N話」表示・4種の並べ替え・次章カードをNUホームとまったく同じように駆動します。
- **Discover** — ランキング、詳細検索（なろうはよもがたり検索と同等）、18歳以上ゲート付きのR18姉妹サイト。
- **機械翻訳でざっと眺める** — ランキングのタイトル・あらすじ・タグに、薄く英語訳を重ねて表示（端末内ML Kitで無料、永続キャッシュ。自分のAIキー経由も可）。翻訳設定は日本サイト専用。
- **ブックマーク** — なろうログインで、改名済みの分類カテゴリごとブックマークライブラリを同期。タイル長押し（または作品ページ）で **カテゴリ間移動・解除** をサイトに書き戻し（NUと同じ感覚）。カクヨムはフォローを同期（サイトがマスター）＋グループ用のクライアント側フォルダ。
- **全サイトの更新通知** — なろうは作者の公開Atomフィード、カクヨムは公開GraphQLでフォローの更新スタンプをポーリング。どちらもNUと同じバックグラウンドチェックで動き、非表示カテゴリは決して通知しません。
- **軽快な作品ページ** — あらすじと章リストは端末内キャッシュ。再訪は一瞬、新刊が実際に出た時だけ再取得。

### 読書とオフライン
- **アプリ内リーダー** — ‹ 前 / 次 › で移動、セピア/ダーク/ライト、セリフ/サンセリフ、文字サイズ調整、作品別JavaScript切替、広告・トラッカー遮断、ブラウザで開く。NUの隠しデコイは計算済みスタイルで除外し、敵対的なホストではWebビューにフォールバック。
- **オフラインライブラリ（標準ePub）** — 作品ごとにオプトイン。読みながら保存、または一括ダウンロード（画面オフでも継続、キューは再起動を生き延びる）。ブックは他の電子書籍アプリへエクスポート・共有可能。保存は常にユーザーの指示によってのみ。
- **長押し日本語辞書** — リーダーで単語を長押しすると読み・品詞・JMdict語義を表示。完全オフライン（Kuromojiトークナイザー＋49.9万項目のJMdict内蔵。有効化時に約80MBを一度だけ展開）。

### AI翻訳とAI表紙（キー持ち込み）
- **章翻訳** — 任意のOpenAI互換エンドポイント経由（OpenRouter、OpenAI、ローカルサーバー）。英語が各段落の下に表示され、オフラインePubに保存。1話ずつでも、保存済み全話の **一括翻訳** でも。
- **novel-mill方式のロックファイル** — `prompt.txt` / `glossary.txt` / `voices.txt` を作品ごとに編集でき、**各話の翻訳後に自動精錬**（新しい固有名詞や声のメモを抽出して次話の文脈に活用）。デスクトップ版 [novel-mill](https://github.com/PatchScratch/novel-mill) のファイルをそのまま貼り付け可能。
- **リーダーレイアウト切替** — 日英両方 / 日本語のみ / 英語のみをリーダーのメニューから即切替。ePub書き出しも同じ選択に従います。
- **AI表紙** — 表紙のない作品（全サイト）に対応。タイトル・ジャンル・あらすじから生成し、タイトルと作者名をアートの作風に合わせた表紙タイポグラフィとして描き込み。プロンプトも自由にカスタマイズ可能。
- **コストは自分で管理** — APIキーは端末内のみ、バックアップには含まれない。翻訳は1話およそ0.5セント、表紙は1枚約$0.01–0.02（下の費用表参照）。

### バックアップ・テーマ・診断
- **1つのzipバックアップ** — リスト・章キャッシュ・表紙・設定をシステムファイルピッカーで。パスワード・セッション・フィードトークンは決して含まない。**「カバーを書き出す（ZIP）」** で表紙だけを端末間で移動（AI表紙含む、マージのみで削除なし）。
- **テーマ** — ライト/ダーク/AMOLEDブラック/Material You に加え、JSONファイルからのカスタムテーマ。
- **デバッグログ** — Cloudflare遭遇・スクレイプ結果・画像失敗を記録。adbで引き出せます（下記）。

## 仕組み

**Novel Updates** にはAPIもCloudflareバイパスもありません。ログイン済みの実際のブラウザセッションを共有するWebViewを組み込み、小さなJavaScriptスニペット（`ScrapeJs.kt`）で各ページを読み、Kotlinで解析します。書き込み（既読化・リスト変更）はウェブサイト自身が使うのと同じエンドポイントを使用します。

**なろう** は公式のドキュメント公開済みJSON API（`api.syosetu.com` — 検索・ランキング・メタデータ。目安〜1リクエスト/秒、当アプリはそれより十分ゆったり）で提供され、ログイン機能（ブックマーク）はWebViewセッションのCookieであなた自身のページを読み取ります。**カクヨム** は公式ウェブサイトが使うのと同じオープンGraphQLエンドポイント（`kakuyomu.jp/graphql`、認証不要）をDiscoverに使い、作品ページ1回のGETで完全なメタデータ＋順序付き目次が得られます。両サイトの本文はNUと同じアプリ内リーダーWebViewに流れます。

**ペース配分ルール** によりアプリは良き市民であり続けます：サイトアクセスは最大でも10秒に1回（Cloudflareページの後は20秒）、表紙ダウンロードは1.5秒間隔、120ジョブごとに10分休むデューティサイクル —— 大きなライブラリも数時間かけて丁寧に流れ込みます。Cloudflareチャレンジの連続発生には警告的にバックオフ（1→5→30分）。実際のチャレンジが出た際、WebViewはまず12秒で自動解除を試みます（最近の管理対象チャレンジは大抵自動で通ります）。自動で解けなかった場合のみユーザーに表示 —— バイパスもヘッドレスの細工も一切ありません。

**変更検出はどこでも保守的**：新着章番号は、保存済みのすべて（リスト行・シリーズキャッシュ・最終既読）より*高い*場合にのみ更新・通知・再取得されます。サイトのプレースホルダや空のスクレイプがキャッシュを消すことは決してありません。

### データフロー

1. リストとシリーズページは `filesDir` キャッシュ（`list_cache.json`、`series_cache/`）から即座に描画。
2. 新規ログイン → **オンボーディング**がリストを読み取り、ライブラリ規模を測り、全体ダウンロード（表紙 → 章ページ、優先リスト優先）をキューに積む。
3. 新着はリリースフィード（自動取得）か間隔を空けたリスト巡回で検出され、変化のあったシリーズは1ページ再スクレイプしてキャッシュへマージ。
4. 既読アクティビティフィードが他端末の既読をマージ。ローカルの進捗が巻き戻ることはありません。
5. エンジンの仕事はすべて `filesDir/sync_queue.json` にチェックポイントされ、再開可能。

## ソースからビルド

1. Android Studioでプロジェクトを開きGradle同期を待つ（JDK 25はStudio同梱JBR。CLIビルドは `JAVA_HOME=<studio>/jbr`）。
2. 実機で実行。初回起動：設定 → **Novel Updatesにログイン** → オンボーディングへ。
3. 単体テスト：`./gradlew :app:testDebugUnitTest`。

## デバッグログ

Cloudflare遭遇（どの検出器・どのURL）、同期/チェック結果、表紙保存、Coil画像失敗、RSSエラーを `filesDir/debug.log`（ローテーション、〜512KB）に記録：

```
adb shell run-as com.patchscratch.novelnotifier cat files/debug.log > debug.log
```

リリースビルドではlogcatミラーも使えます：`adb logcat -s NovelNotifier`

## テーマ

設定 → **表示** から内蔵ルックを選べます：**システムに従う**（ライト/ダーク、既定）、ライト、ダーク、**AMOLEDブラック**（OLED向け真黒）、**ウォールペーパーの色**（Material You、Android 12+）。選択はレイアウトや通知設定とともにバックアップ内を移動します。

### カスタムテーマ

JSONファイルで自分好みのテーマにもできます：

1. 設定 → 表示で **テーマテンプレートを保存** — 内蔵グリーンパレットで埋めた完全に動作するスターターファイル（`novelnotifier-theme.json`）をファイルピッカーで書き出します。
2. 好きなテキストエディタで色を編集。不要な行は削除してOK — 省略した役割は内蔵グリーンにフォールバック。
3. **テーマファイルをインポート（JSON）…** で読み込み。即時適用され、ピッカーに **Custom: *名前*** として表示されます。

形式：

```json
{
  "name": "Ocean",
  "light": {
    "primary": "#0B57D0",
    "background": "#F8F9FF",
    "surface": "#F8F9FF"
  },
  "dark": {
    "primary": "#A8C7FA",
    "background": "#0F1420",
    "surface": "#0F1420"
  }
}
```

ルール：

- `"light"` と `"dark"` はそれぞれ省略可ですが、**最低1つは必須**。両方あればシステムのライト/ダークに追従、片方だけならそのスキーマで固定。
- 色は `"#RRGGBB"` または `"#AARRGGBB"`（アルファが先頭）。
- 設定可能な役割：`primary`、`onPrimary`、`primaryContainer`、`onPrimaryContainer`、`secondary`、`onSecondary`、`secondaryContainer`、`onSecondaryContainer`、`tertiary`、`onTertiary`、`tertiaryContainer`、`onTertiaryContainer`、`background`、`onBackground`、`surface`、`onSurface`、`surfaceVariant`、`onSurfaceVariant`、`outline`。
- 各色は対応する `on…` 相手とペアにしてください（例：`background` + `onBackground`）。文字が読めなくなる可能性があります — コントラストは自分の責任で、アプリは検証しません。
- 誤字は派手に失敗します：不明な役割や不正な色は、問題を名指ししたメッセージとともにインポートを中断。中途半端な適用はありません。
- インポートされたファイルはアプリ内に保存され、バックアップにコピーされるため、新しい端末にもライブラリと一緒に移動します。

## バックアップと機種変更

表紙だけを端末間で移すには（再ダウンロード元のないAI表紙を含む）、同じセクションの **「カバーを書き出す（ZIP）」** —— 読み込み側はマージのみで、削除は行いません。

設定 → **ライブラリをバックアップ** でzipを1つファイルピッカー経由で書き出し — Google Drive、OneDrive、USBメモリなどへ。新端末では：インストール → **バックアップから復元** → ログイン。ライブラリと表紙が即座に現れ、同期エンジンが古い分を補完します。バックアップは意図的に認証情報とフィードトークンを除外 — 復元済み端末は新規ログインを行い、フィードリンクを自動で再取得します。

## AI翻訳・AI表紙のコスト（キー持ち込み）

章翻訳とAI表紙生成は、どのOpenAI互換エンドポイント（OpenRouter、OpenAI、ローカルサーバー）経由でも動作します — キーは自分のものを設定 → 翻訳で一度設定するだけ。翻訳は原文とともにオフラインePubライブラリに保存され（リーダーで各日本語段落の下に英語が表示されます）、バックアップ・エクスポートで他端末にも運べます。APIキーは端末から出ず、バックアップからも除外されます。

典型的なウェブ小説1章（約3,000字 ≈ 入力2,500〜3,000トークン、質の高い英訳で出力2,000〜2,500トークン、＋プロンプトオーバーヘッド約500トークン）あたりの概算コスト。価格は**100万トークンあたり**（入力/出力）、[OpenRouter](https://openrouter.ai/models) と [AICostNest](https://www.aicostnest.com) の2026年価格ガイドから — 依存する前に最新価格を確認してください：

| 層 | モデル例（入/出 $/M） | 1章あたり | 300章の長編 |
|---|---|---|---|
| エコノミー | Gemini 2.5 Flash-Lite ($0.10/$0.40)、GPT-4o-mini ($0.15/$0.60)、DeepSeek V3 (~$0.28/$0.42) | ~$0.001–0.003 | ~$0.30–0.90 |
| **品質重視（推奨）** | **GPT-4.1-mini ($0.40/$1.60)**、Gemini 2.5 Flash ($0.30/$2.50)、Claude Haiku 4.5 ($1.00/$5.00) | ~$0.004–0.015 | ~$1.20–4.50 |
| プレミアム | Claude Sonnet 4.5 ($3/$15)、GPT-4.1 ($2/$8) | ~$0.03–0.05 | ~$9–15 |

目安：**品質重視**モデルなら1章およそ0.5セント — 600章の大作で約 **$3–8**。エコノミーモデルは約10分の1ですが文芸的な文章には修正が多く必要です。プレミアムモデルはお気に入りの章向けで、図書館全体向けではありません。用語集（キャラ・用語表をプロンプトに含める）は1章約500入力トークンの追加で名前の一貫性を改善します。

**AI表紙：** サイトに表紙のないシリーズでは、ページに「カバーを生成（AI）」ボタンが出ます（3サイト共通）。タイトル・ジャンル・あらすじからライトノベル表紙風のアートを生成し、タイトルと作者名をアートの作風に合わせた表紙タイポグラフィとして描き込みます。生成物はダウンロードした表紙と全く同じ扱いで保存され、グリッド・バックアップ・転送で同一に扱われます。典型的な画像モデルは**1枚約$0.01–0.02**（実測：Seedream 5 Flashで$0.018）。あらすじなどのサイト情報はML Kitによる端末内の無料翻訳も可能です — 設定を参照。
